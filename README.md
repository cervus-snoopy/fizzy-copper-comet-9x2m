## The line

> My smartwatch logged my heart stopping three times last night, and the fourth time, it logged someone else's starting.

One sentence, 118 characters. The field is full of dogs staring at empty chairs, ultrasounds with a second heartbeat, black boxes and daughters drawing faceless men — this one is the angle nobody wrote: a smartwatch, a body, and a possession implied in a single log entry. Three stops, then someone else's heart starts.

## How it runs

`main.py` (Python 3, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` — UTF-8, no trailing newline — and leaves the file readable by every user (0644, folders 0755).

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
